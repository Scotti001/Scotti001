## Projetos em destaque

### 🌿 Plant Injury AI

Solução de visão computacional para estimar o percentual de injúria visual em plantas a partir de fotografias. O projeto reúne preparação e rotulagem de dados, treinamento com PyTorch, API REST com FastAPI, validação humana e integração com Firebase e Google Cloud.

`Python` `PyTorch` `FastAPI` `Firebase` `Google Cloud` `Visão Computacional`

Sistema full stack voltado à gestão zootécnica, com recursos para controle reprodutivo, sanitário e produtivo. Inclui modelagem de dados, integração entre frontend e backend, APIs REST, dashboards, relatórios e recursos de IoT.

`Flutter` `Node.js` `MongoDB` `APIs REST` `IoT`
